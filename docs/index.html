フリック

ランダムに現れる的をクリック。的を撃ち抜くと、次の的が現れます。素早く正確に当てるほどスコアが高くなり、連続命中でボーナスが加算されます。

02

トラッキング

左ボタンを押したまま、動く的をカーソルで追い続けます。セッション全体のうち、押しながら的に重なっていた時間が追従率になります。

磨ける力 滑らかな追従・持続的な集中
03

反応速度

的が現れるまで待ち、出現した瞬間にクリック。的は一定時間で消えます。待機中のクリックはミスになるため、焦らず出現を見極めましょう。

磨ける力 視覚反応・瞬間的な判断
