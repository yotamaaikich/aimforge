# Aim trainer

フリック・トラッキング・反応速度を練習するシンプルなWebアプリ。

**プレイ:** https://yotamaaikich.github.io/aimforge/

## 操作

モード・難易度・時間を選んで「開始」を押します。

- フリック：表示される的をクリック。
- トラッキング：左ボタンを押したまま動く的を追跡。
- 反応速度：的が現れたらクリック。待機中のクリックはミスになります。
- Space：開始・一時停止・再開。フォームにフォーカスがある場合はその操作を優先。
- Esc：中断。中断した練習は記録しません。

タブを離れると自動で一時停止します。全画面表示と効果音も利用できます。

「記録」から最新100件の結果とCSV出力を開けます。記録はブラウザのlocalStorageに保存されます。以前のバージョンの記録も引き継ぎます。同じモード・難易度・時間でスコアを比較してください。トラッキングの追従率は、押しながら的に重なっていた時間を練習時間全体で割った値です。

## 開発

Node.js 20以降。依存パッケージ不要。

```sh
npm start
# http://127.0.0.1:4173/
npm test
```

`docs/` が静的サイト本体です。`engine.js` がゲーム処理、`app.js` が画面制御。外部フォントやライブラリの読込はありません。

## 公開

GitHub Pagesの配信元は `main` ブランチの `/docs` です。プッシュすると自動で更新されます。
