# AIMFORGE

狙いを、研ぎ澄ませ。日本語のエイムトレーニング Web アプリ。

**プレイ:** https://yotamaaikich.github.io/aimforge/

## 機能

- フリック：ランダムに出現する的を正確にクリック。反応速度と連続命中に応じたスコア。
- トラッキング：左ボタンを押しながら動く的を追跡。練習時間全体に対する追従率。
- 反応速度：時間制限つきの的をクリック。平均反応時間・見逃し回数を記録。
- 3段階の難易度、30・60・90秒のセッション。
- 一時停止、自動一時停止、全画面、効果音。
- 最新100件の履歴・自己ベスト・精度チャート・CSV出力。
- PC・タブレット・スマートフォン対応。マウス操作を推奨。

記録は `localStorage` に保存されます。同じ端末・ブラウザで利用してください。ブラウザのデータを削除すると記録も削除されます。アカウント登録やサーバーは不要です。外部リクエストは Google Fonts のフォント読込のみで、フォントを取得できなくてもフォールバック書体で動作します。

## 開発

Node.js 20 以降。依存パッケージのインストールは不要です。

```sh
npm start
# http://127.0.0.1:4173/
npm test
```

`docs/` がそのまま配信可能な静的サイトです。ゲーム本体は `docs/engine.js`、画面制御は `docs/app.js` に分離しています。

## GitHub Pages

リポジトリの **Settings → Pages → Deploy from a branch → main → /docs** を配信元に設定します。以後 `main` にプッシュすると自動的に公開内容が更新されます。

## 操作

- 左クリック：射撃。トラッキングでは左ボタンを押し続けて追跡。
- Space：開始・一時停止・再開（ボタンにフォーカスがある場合はそのボタンを操作）。
- Esc：セッションを中断。中断したセッションは保存しません。
- タブ切替・ウィンドウが非アクティブになると自動で一時停止します。

スコアの比較は同じモード・難易度・時間で行ってください。ダッシュボードのスコア自己ベストはフリック / STANDARD / 30秒の記録です。最高命中率はクリック系モード、最速平均反応は反応速度モードの記録を使います。
